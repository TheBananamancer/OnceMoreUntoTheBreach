The addition of a dedicated function to display the game title is a good practice for improving user experience. It centralizes the presentation and makes it easier to modify or localize the title in the future without hunting through code. Using a function also promotes code reusability if the title needs to be displayed in multiple locations (e.g., main menu, credits screen).
